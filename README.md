# 🎬 CineVerse – Movie Ticket Booking Platform

## 📌 Overview

CineVerse is a full-stack movie ticket booking platform developed using the MERN stack. The platform allows users to explore movies, check show timings, select seats, and book tickets through a smooth and user-friendly interface.

This project was built to understand real-world web application architecture, authentication systems, database management, API integration, and responsive UI design.

---

## 🚀 Features

* 🔐 User Authentication & Authorization
* 🎥 Browse Movies & Show Details
* 🪑 Real-Time Seat Selection
* 🕒 Show Timing Management
* 💳 Online Booking Workflow
* 📱 Responsive User Interface
* 🗂 Booking History Tracking
* 🛠 Admin Dashboard for Movie & Show Management
* ⚡ Fast and Smooth User Experience

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/cineverse.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd cineverse
```

### 3️⃣ Install Dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd server
npm install
```

---

## ▶️ Run the Project

### Start Backend

```bash
npm start
```

### Start Frontend

```bash
npm run dev
```
